# KDIGO AKI Staging and ICU Mortality — MIMIC-IV v3.1 Analysis

This repository contains the analysis code for the retrospective cohort study:

**"Association of KDIGO Creatinine-Based AKI Staging with ICU Mortality: A Retrospective Cohort Study Using MIMIC-IV v3.1"**

Target journal: *Renal Failure* (Taylor & Francis)

---

## Study Overview

- **Database:** MIMIC-IV v3.1 (PhysioNet, 2008–2022)
- **Cohort:** 84,167 adult ICU stays
- **Exposure:** KDIGO creatinine-based AKI staging (Stage 0–3)
- **Outcome:** In-hospital ICU mortality
- **Primary analysis:** Incremental logistic regression (Models A–C), Cox regression, Kaplan–Meier, restricted cubic splines, and five pre-specified sensitivity analyses

---

## Repository Structure

| File | Purpose |
|------|---------|
| `kdigo_revised_data.py` | Data extraction from MIMIC-IV v3.1 (PostgreSQL) |
| `kdigo_revised_stats.py` | Statistical analyses: logistic, Cox, KM, RCS, landmark, sensitivity |
| `kdigo_prism_figures.py` | Generate all 8 main figures and 4 supplementary figures |
| `calculate_evalue.py` | E-value sensitivity analysis for unmeasured confounding |
| `generate_dag.py` | Generate directed acyclic graph (DAG) for causal structure |
| `generate_supplementary_tables.py` | Format Tables S1–S7 as DOCX |
| `generate_tables_docx.py` | Extract Tables 1–2 as independent DOCX |
| `generate_submission_docs.py` / `generate_submission_package.py` | Build submission documents |
| `convert_to_docx.py` | Markdown → DOCX converter |
| `requirements.txt` | Python dependencies with pinned versions |
| `results/` | Analysis outputs (CSV/JSON) generated by the scripts |

## Usage

### 1. Environment setup

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Data extraction

Configure PostgreSQL/MIMIC-IV connection in `kdigo_revised_data.py`, then run:

```bash
python kdigo_revised_data.py
```

### 3. Statistical analysis

```bash
python kdigo_revised_stats.py
```

### 4. Figures

```bash
python kdigo_prism_figures.py
```

### 5. E-value and DAG (for risk-avoidance review)

```bash
python calculate_evalue.py
python generate_dag.py
```

## Key Results

| Model | KDIGO Stage 1 | Stage 2 | Stage 3 |
|-------|--------------|---------|---------|
| Model A (unadjusted) OR (95% CI) | 2.76 (2.60–2.94) | 5.26 (4.78–5.80) | 7.03 (6.59–7.50) |
| Model B (adjusted) aOR (95% CI) | 1.89 (1.77–2.01) | 2.98 (2.69–3.30) | 2.88 (2.66–3.12) |
| Model B HR (95% CI) | 1.62 (1.54–1.71) | 2.26 (2.09–2.44) | 2.04 (1.92–2.17) |
| Model B E-value (aOR) | 2.98 | 4.77 | 4.62 |

E-values indicate strong-to-extreme robustness to unmeasured confounding.
